# media-launcher Chrome Extension

Browser extension for Chrome/Chromium that sends YouTube videos and other media to an external player (mpv) via the media-launcher Go server.

## Development

pnpm install
pnpm dev

## Build

pnpm build

Output goes to dist/.

## Load in Chrome

1. Go to chrome://extensions
2. Enable Developer mode
3. Click Load unpacked
4. Select the dist/ directory
